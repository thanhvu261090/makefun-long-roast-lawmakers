One satirical sentence roasting lawmakers who would regulate AI but cannot convert a file to PDF.

> "Congress passed a 400-page law telling AI exactly how to think, then called IT because nobody in the room could turn the bill itself into a PDF."

## How it works

`main.py` holds the entry line as a constant, checks it against the kit's gate (UTF-8 text, 1–320 characters, not only whitespace, a single sentence on one line), and writes it to `/output/entry.txt` when run with `python3 main.py`.
